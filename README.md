## 🛠️ 开发

有兴趣为 Zdan Code 做出贡献吗？请按照以下步骤设置您的开发环境：

1.  **克隆仓库：**
    ```bash
    git clone <your-repository-url>
    cd zdan-code
    ```

2.  **安装依赖：**
    ```bash
    npm install
    # 或
    yarn install
    ```

3.  **运行开发服务器：**
    ```bash
    npm run dev
    # 或
    yarn dev
    ```
